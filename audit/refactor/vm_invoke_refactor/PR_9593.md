# PR #9593 — bpf_loader: extract vm execute to program-runtime

- **Commit:** `a5b22fd5ea7f1a3d8f9120d9aeb8ac6af77d7a5e`
- **Date:** 2026-01-22
- **Files changed:** 11 (427 insertions, 408 deletions)

## Summary

Extracts the VM provisioning and execution machinery from
`programs/bpf_loader/src/lib.rs` into a new `program-runtime/src/vm.rs`
module. Moves `MEMORY_POOL`, `calculate_heap_cost`, `create_vm`,
`create_memory_mapping`, `create_vm!` macro, and `execute`. Also moves
the `cfg-if` dependency from bpf_loader to program-runtime.

## File Summary

### Category A: Pure Moves

| Item | Source | Destination |
|------|--------|------------|
| `MEMORY_POOL` thread-local | `bpf_loader/src/lib.rs` | `program-runtime/src/vm.rs` |
| `calculate_heap_cost()` | `bpf_loader/src/lib.rs` | `program-runtime/src/vm.rs` |
| `create_vm()` function | `bpf_loader/src/lib.rs` | `program-runtime/src/vm.rs` |
| `create_memory_mapping()` | `bpf_loader/src/lib.rs` | `program-runtime/src/vm.rs` |

| `execute()` function | `bpf_loader/src/lib.rs` | `program-runtime/src/vm.rs` |

All function bodies are identical. The `create_vm!` macro references
updated from `$crate::calculate_heap_cost` / `$crate::MEMORY_POOL` /
`$crate::create_vm` to `$crate::__private::calculate_heap_cost` /
`$crate::__private::MEMORY_POOL` / `$crate::__private::create_vm`
(routed through the `__private` re-export module for cross-crate macro
hygiene).

### Category B: Structural Changes

- **`__private` module updated** in `program-runtime/src/lib.rs` to
  re-export `MEMORY_POOL`, `calculate_heap_cost`, and `create_vm` from
  the new `vm` module. This is the standard pattern for making items
  available to exported macros.
- **Feature flags added** to program-runtime: `sbpf-debugger` (forwards
  to `solana-sbpf/debugger`) and `svm-internal`. These were previously
  only in bpf_loader. The `sbpf-debugger` feature in bpf_loader now
  also enables `solana-program-runtime/sbpf-debugger`.
- **`cfg-if` dependency** moved from bpf_loader to program-runtime
  (used by `cfg_if!` block in the `execute` function for JIT selection).
- **Import path updates** at all call sites:
  - `ledger-tool`: `solana_bpf_loader_program::create_vm` -> `solana_program_runtime::create_vm`
  - `loader-v4`: `solana_bpf_loader_program::execute` -> `solana_program_runtime::vm::execute`
  - `programs/sbf/benches`: `solana_bpf_loader_program::create_vm` -> `solana_program_runtime::create_vm`

### Category C: Behavioral Changes

**None.** No error type changes. No logic changes. All functions are
byte-for-byte identical between source and destination (modulo the
`$crate::` path adjustments in the macro).

### Category D: Test-Only Changes
