## Summary

Final PR in the CPI module extraction chain. Moves the Rust and C
translation function bodies out of the `SyscallInvokeSignedRust` and
`SyscallInvokeSignedC` trait impls in `syscalls/src/cpi.rs` into
standalone public functions in `program-runtime/src/cpi.rs`. After this
PR, `syscalls/src/cpi.rs` only contains the `declare_builtin_function!`
wrappers that delegate to program-runtime. Also narrows visibility on
several items that are now module-internal.

## File Summary

### Category A: Pure Moves

Functions extracted from trait impl bodies to standalone functions:

| Old (trait method body) | New (standalone fn) |
|------------------------|---------------------|
| `SyscallInvokeSignedRust::translate_instruction` | `translate_instruction_rust()` |
| `SyscallInvokeSignedRust::translate_accounts` | `translate_accounts_rust()` |
| `SyscallInvokeSignedRust::translate_signers` | `translate_signers_rust()` |
| `SyscallInvokeSignedC::translate_instruction` | `translate_instruction_c()` |
| `SyscallInvokeSignedC::translate_accounts` | `translate_accounts_c()` |
| `SyscallInvokeSignedC::translate_signers` | `translate_signers_c()` |

Also moved:
- `MAX_SIGNERS` constant (from `syscalls/src/lib.rs`)
- `solana-stable-layout` dependency (added to program-runtime/Cargo.toml)

### Category B: Structural Changes

**Visibility narrowed** — now that callers are in the same module,
several items go from `pub` to private:
- `check_instruction_size`, `check_account_infos`, `check_authorized_program`
- `translate_account_infos`, `translate_and_update_accounts`
- `update_callee_account`, `update_caller_account_region`, `update_caller_account`
- `CallerAccount::from_sol_account_info`
- C repr structs: `SolInstruction`, `SolAccountMeta`, `SolAccountInfo`,
  `SolSignerSeedC`, `SolSignerSeedsC`

This is a tightening of the API surface — strictly safer.

**`AccountInfo` moved** from production to test-only imports in
`syscalls/src/lib.rs`.

### Category C: Behavioral Changes

Error variant changes in the signers translation functions:

| Function | Old | New |
|----------|-----|-----|
| `translate_signers_rust` | `SyscallError::TooManySigners` | `CpiError::TooManySigners` |
| `translate_signers_rust` | `SyscallError::BadSeeds(err)` | `CpiError::BadSeeds(err)` |
| `translate_signers_c` | `SyscallError::TooManySigners` | `CpiError::TooManySigners` |
| `translate_signers_c` | `SyscallError::BadSeeds(err)` | `CpiError::BadSeeds(err)` |

Same error consolidation pattern. Error messages identical. All boxed
as `Box<dyn Error>`.

**Assessment:** SAFE.

### Category D: Test-Only Changes

All remaining tests and test infrastructure moved from
`syscalls/src/cpi.rs` to `program-runtime/src/cpi.rs`:
- `MockInstruction`, `mock_signers()`, and remaining helpers
- `test_translate_instruction`, `test_translate_signers`,
  `test_translate_accounts_rust`

Tests now call the standalone functions (e.g. `translate_instruction_rust()`)
instead of the trait methods (e.g. `SyscallInvokeSignedRust::translate_instruction()`).
Same test logic, same assertions.
